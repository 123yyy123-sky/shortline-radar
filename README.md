# 交易台 Trading Desk

一个窗口管三条线：**短线打板**（A股涨停扫描）、**B线路选股**（题材 ETF 右侧突破）、**R3 卫星轮动**（ETF 每 10 个交易日换仓）。
本地跑，浏览器看，不依赖任何云服务，也不替你下单。

> 原名「短线雷达」；2026-10-24 加入 B线路与三价台账后改名。旧目录 `F:/Ai/apps/短线雷达` 留了一个目录联接指向本目录，老快捷方式照样能点。

![扫描界面](docs/screenshot-scan.png)

---

## 它解决什么问题

打板最难的不是判断，是**在一瞬间筛掉不该打的**。这个工具做三件事：

1. **盘中扫全市场**（5,500+ 只，约 25 秒），按六道条件过滤，只剩符合统计优势的几只
2. **告诉你差在哪一步** —— 每只被剔除的票都写明原因，不是简单藏起来
3. **管住卖出** —— 算好跌停价，T+1 早上照单挂出去就行

## 先看结论，再看代码

十年全市场日K（1,034 万行 / 5,576 只）回测出来的东西，有些反直觉：

| 结论 | 数字 |
|---|---|
| **打板赚的钱全在隔夜跳空里** | 封住 +1.975%（66.2%）；炸板 **−5.607%**（4.5%）；按 65/35 加权 **−0.682%**，11/11 年负 |
| **炸板率是唯一门槛** | 现在 35.0%，翻正需 ≤**26.05%**。日线变量最多压到 30.6%，碰不到 |
| **「缩量 + 开盘 3~9% = +4.10%」已作废** | 那是只算封住样本的幸存者偏差。新口径最优是「开盘 1~3% + 价格≥20」，四项叠加只 **+0.020%** |
| **无过滤的接力是负期望** | −0.219% / 胜率 44.7%。越像要涨停越亏，追高 1% 吃掉 1% |
| **半路板可执行版（2026-10-24 重写）** | 20cm + T=5% + **高开>2%** + **次日收盘卖** → **+1.381% / 50.1%**，7/7 年正；剔 2024 只剩 +0.587%，按 **+0.35~0.45% 净**预期 |
| **连板不值得打** | 炸板亏 10%~11%，而封住只比首板多赚 0.5 个百分点（连板口径 −1.854%） |

完整推导、每张分档表和 8 条限界见 [docs/STRATEGY.md](docs/STRATEGY.md)。

**一句话记住**：盘中只认一个条件 —— **量比 < 1**；次日只做一个动作 —— **9:25 挂跌停价卖**；买不进只做一件事 —— **放下手机，等下一个**。

## 快速开始

需要 Python 3.9+，不装第三方库也能跑（演示模式零依赖）。

```bash
git clone https://github.com/123yyy123-sky/trading-desk.git
cd trading-desk
python app.py
```

浏览器会自动打开 <http://127.0.0.1:8848/>。

**第一次跑起来看到的是演示数据**（构造的 11 只票，覆盖所有判定分支）。界面顶部会有橙色提示。想看真实行情，接一个数据源：

```bash
cp config.example.json config.json
# 编辑 config.json，填入行情源
```

Windows 上也可以直接双击 `run.bat`。

想做成一键启动的桌面图标：

```bash
python tools/install_shortcut.py  # 或加 --name "涨停雷达" 自定义名字
```

会在桌面生成**两个**图标：

| 图标 | 动作 |
|---|---|
| 交易台 | 双击启动，浏览器自动打开，**不弹黑窗口** |
| 停止交易台 | 双击就把后台的服务关掉 |

加 `--force` 覆盖同名文件；加 `--console` 保留控制台窗口（想直接看日志的时候用）。

**为什么没有黑窗口**：有窗口时那个黑框就是服务本体，关掉它服务就停，不关就一直占着任务栏。现在进程在后台静默跑，日志写 `data/app.log`。

**注意一个坑**：无窗口启动后，你调用的每一个命令行工具都会自己弹一个控制台窗口。本程序已经用 `CREATE_NO_WINDOW` 把它堵掉了，如果你自己二次开发时新增子进程调用，记得同样处理，否则黑窗会一直弹。

**它什么时候停**：

- 关掉所有浏览器标签页 → 约 2 分钟后自己退出（`config.json` 的 `web.idle_exit_seconds`，改成 `0` 就常驻不清）
- 想立刻停 → 双击「停止交易台」
- 更想常驻 → `python app.py --idle-exit 0`

**启动失败会怎样**：无窗口模式下没有控制台，出错本来是静默的。现在会弹一个系统对话框，直接显示错误原因，同时写进 `data/app.log`。

## 数据源

### 方案 A：接自己的行情源（推荐）

软件只需要两样东西：**全市场实时快照** + **涨停池**。默认实现走 `hithink-finance` 命令行工具：

1. 装好 CLI，确认 `hithink-finance symbol list --limit 3` 能返回数据
2. 让它能被找到 —— 以下任选一种：
   - **推荐**：`python tools/make_vendor_shim.py`，自动探测本机 node 和 CLI，
     在 `vendor/` 生成一个写死绝对路径的转发脚本
   - 把可执行文件放进 `vendor/`
   - 设环境变量 `HITHINK_CLI=<路径>`
   - 在 `config.json` 里填 `hithink.cli_path`
3. `config.json` 保持 `"data_source": "hithink"`

> **为什么要用转发脚本**：从资源管理器双击启动时，进程拿到的是系统持久化的
> PATH。node 常常只装在某个带版本的目录里、没进 PATH，于是软件找不到 CLI，
> 一按扫描就报「找不到 hithink-finance」——在终端里手动跑却是好的。
> 转发脚本把 node 和 CLI 的绝对路径写死，就不依赖 PATH 了。
> node 升级换目录后重跑一次即可。

## 按扫描没反应 / 报「找不到 hithink-finance」

先跑自检，它会直接指出是哪一环断了：

```bash
python tools/doctor.py
```

正常输出长这样（`[WARN]` 可以不管，`[FAIL]` 才是问题）：

```
[ OK ] Python 3.11.9
[ OK ] config.json           : data_source=hithink
[WARN] PATH 里的 node       : 没有
[WARN] PATH 里的 hithink CLI : 没有
[ OK ] CLI 实际路径         : ...\vendor\hithink-finance.cmd
[ OK ] 来源                 : vendor/ 转发脚本
[ OK ] CLI 回话             : rc=0 0.1.13
[ OK ] 基准数据             : 5576 只，截至 2026-10-20
```

对照处理：

| 症状 | 原因 | 处理 |
|---|---|---|
| `CLI 实际路径` 那项是 FAIL，提示找不到 hithink-finance | 双击启动的进程 PATH 里没有 node | `python tools/make_vendor_shim.py` |
| CLI 回话 rc≠0 | CLI 自身没登录 / 没配 key | 手动跑 `hithink-finance --version` 排查 |
| 基准数据 asof 太旧 | `data/benchmark.json` 是某天快照 | `python tools/build_benchmark.py` |
| 双击图标闪一下就没了，浏览器没打开 | 端口被上一个实例占着 | 现在会自动接管：打开 `http://127.0.0.1:8848` 就是它在跑 |
| 页面能开，点扫描一直转圈 | 全市场 5,500 只要 30 秒左右 | 等它转完；转超过 2 分钟看 `data/app.log` |
| 双击后完全没反应 | 无窗口模式下看不到报错 | 现在会弹出对话框说明原因；也可以看 `data/app.log` 或跑 `python tools/doctor.py` |
| 一打开就不停弹黑色小窗 | pythonw 没有控制台，每次调命令行工具都会给它新建一个控制台窗口 | 已在 `shortline/datasource.py` 里用 `CREATE_NO_WINDOW` 修掉；自己加子进程调用要照做 |

跑完想确认整条链路通不通，用自带的自检：

```bash
python tools/selftest.py          # 状态 -> 触发扫描 -> 轮询 -> 打印漏斗
```

## 界面

五个页面，都用 `?tab=` 可以直接打开（`scan` / `bline` / `r3` / `hold` / `help`）。

### 扫描结果

顶部是**漏斗**：全市场 → 涨幅达标 → 开盘达标 → 量比达标 → 全条件 → 已封板。每一步剩多少、转化率多少，一眼能看出今天市场是什么样子。

结果分三组：

- **可打** — 全条件通过且已封板。挂涨停价排队，买不进就空仓
- **盯住** — 条件都够但还没封。封不上就不买，别抢跑
- **剔除** — 每行最后一列写着差在哪一步

点「筛选条件」可以改阈值，保存后自动重扫。默认值就是回测里跑出正期望的那一组，**没看懂之前别动**。

### B线路选股（v1.1.0 新增）

第二个页签。判定只有一份，在工作区的 `scan_watchlist.py`（真源 [[B线路操作手册]] / §3A.1、§3A.3），
本程序只搬结果 + 让你改价，**不重算档位、不重算 focus**。

| 显示 | 含义 |
|---|---|
| 档位 | 大盘四档 A/B/C/D（A=3/3 站上 MA20，B=沪深300 距 MA20 ±1.5%，C=恰好 2/3，D=≤1/3） |
| focus 命中 | 单日命中 ≥2 只才算；1 只降级观察；0 只空仓等主线 |
| 观察池 · 三价台账 | 池内全部标的：现价 / 距 60 日高 / vol20 / 乖离20 / **买入价 / 止损价 / 卖出参考** / 距止损 / 参考份数 |

三价默认值：**买入价 = 收盘**，**止损价 = 收盘 − 1×N**（N=ATR20，突破式口径），**卖出参考 = MA20**（跌回均线走人）。
参考份数按试探仓 750 元 ÷（价×100）取整手，改价后份数自动跟着变。

「盘中口径」勾上就用实时价拼当日半根 K（`--live`），收盘后自动回到收盘口径。

**观察池名单可增删**（卡片右上「编辑名单」）：

| 动作 | 走哪个脚本 | 做了什么 |
|---|---|---|
| 加池 | `trading/_add_watchlist.py` | 推断 `sz/sh` 与前缀 secid、查名称、**先备份**、写盘后复验（数量/重复/在册） |
| 出池 | `trading/_prune_watchlist.py` | **物理删行** + 写 `removed_log`（日期/名称/代码/理由）+ 备份 |

出池**不能只改 `status=drop`** —— 那只影响显示，雷达照扫，等于没出池（159587 就是这么被扫了一周的）。
程序里删完会自动重扫一遍（约 20 秒）。删前会让你填理由，理由进 `removed_log`。

### 三价台账（买入价 / 卖出价 / 止损价都能改）

两个表格里的价格（R3 的成本/止损/卖出参考、B线路的买入/止损/卖出参考）都是**点一下就能改**的：

| 操作 | 效果 |
|---|---|
| 点数字 | 变成输入框，回车保存、Esc 取消、清空 = 回默认值 |
| 改过的数 | 标蓝 + 前面一个蓝点（跟行情软件的「自设价」一个意思） |
| 行尾 ↺ | 清掉这只的全部自定义价，回到规则算的默认值 |

存的地方是 `data/levels.json`，只记**你改过的字段**，没改的永远跟规则走。
改价**不重跑脚本**，也不影响「是否调仓 / 买谁 / 是否破止损」这些判定口径 —— 但破止损状态会按你设的止损价重算，
所以自己把止损调宽了，等于自己放弃了那道闸门。

### B线路持仓（v1.1.1 新增）

候选成交之后，这笔就从「打算怎么做」变成「已经做了什么」——记到第三个卡片里，存在 `data/bline_positions.json`。

**为什么单独一份**：候选表的止损是 `收盘 − 1×N`（预估），成交后的止损必须按 `实际成交价 − 1×N` 重新写定。
混在一份里，改候选止损会顺手改掉持仓止损。

| 每行都算 | 触发条件 | 动作 |
|---|---|---|
| 价格止损 | 收盘 ≤ 止损价 | 次日开盘清仓该只，不摊平 |
| 回 MA20 | 收盘 < MA20 | 按出场规则离场 |
| 时间止损 | 普通仓满 20 个交易日 / C 类 15 个 | 收盘离场，不论盈亏 |
| 浮盈阶梯 | 浮盈 ≥15% → 止损收紧到 max(写定, 期间最高×0.92)；曾达 +20% → 抬到成本 | 只收紧、只朝盈利移、**只收盘判** |

- 止损默认 **成交价 − 1×N**（N=ATR20）；ATR 取不到退 **成本×0.95**。都写不进就点数字自己写。
- 份数、成本、止损、卖出参考四个格子同样**点一下就能改**；清空止损 = 回到自动口径。
- 「期间最高」取该只**买入日之后的日线最高价**（腾讯前复权日线），不是程序观察到的最高价。
- 「持有几个交易日」按日线数，取不到退按工作日估算（会标明）。
- 顶部状态条会显示 **B线持仓 N 只**，有破线的标红；卡片头显示市值 / 6,000 占用比例。
- 只提示，不下单：程序不会替你卖，也不改券商。

### 持仓卖出

![持仓界面](docs/screenshot-hold.png)

记一笔买入，它会算好 T+1 该挂的跌停价。价格取当天真实昨收，取不到会留空让你手填 —— 不拿旧数据瞎算。

### R3 卫星轮动（v1.0.8 新增）

第三个页签，接的是**另一套系统**：ETF 卫星动量轮动（每 10 个交易日按 60 日涨幅换 2 只，沪深300 跌破 MA20 就空仓）。
规则实现在交易工作区的 `r3_rotation.py`（唯一计算源），本程序只负责显示、记账和推送 —— **不重写任何规则**。

| 你要的 | 在哪 |
|---|---|
| 排除名单 | 池内前 5 卡片下方：填代码 → 加入排除（**默认空 = 与回测口径一致**；非空会在报告标注「回测未覆盖」） |
| 建议买入价 | 买入清单第 4 列（= 基准日收盘，明早按**开盘实际价**成交） |
| 挂单上限 | 第 5 列（= 建议买入价 ×1.02，高开超过就放弃这只、钱留现金） |
| 止损价 / 止损距离 | 买入清单第 6、7 列；持仓表「止损价 / 距止损」 |
| R3 持仓 | 持仓表：份数 / 成本 / 现价 / 浮盈 / 止损价 / 距止损 / 状态；成交后在页内**记一笔**（填真实成交价） |
| 推送 | 飞书群，只在真要做动作时推（调仓日有买卖 / 持仓破止损），同一动作当天只推一次 |

两个按钮管数据：**重算**（重跑脚本）、**更新数据**（后台跑 `_update_hist.py` 刷 ETF/指数日K，约 1~3 分钟）。
`?tab=r3&asof=2026-08-18` 可以回放某天的调仓清单，页面上会标「回放」并给「回到最新」。

配置全在 `config.json` 的 `r3` 段：

- `workdir` / `script`：R3 脚本所在目录（留空 = 没接，页面会报错但其他功能不受影响）
- `stop_mode`：`ma20`（默认，收盘破 MA20）/ `atr`（成本−1×ATR20）/ `pct`（成本×0.95）/ `none`（不设，纯回测口径）
- `push.auto`：程序开着时每 `check_seconds` 秒检查一次，只在 `after`~`until`（默认 15:00~22:00）窗口内有动作才发
- `push.chat_id`：留空用内置的 ETF 群

> ⚠️ 回测口径里 **R3 没有个股止损**（满仓 2 只无止损，21% 回撤是真实成本）。这里显示的止损价是**叠加的风控线、未回测**：只让这只提前离场、钱回现金等下次调仓，不加仓不摊平。
> 止损价随均线移动，**可能高于成本** —— 那说明成交价填错了，或者这只买入时就该被「先滤 MA20」剔掉。

程序没开也要推？`python app.py --push-only` 跑一次就退出（不开界面），可以挂 Windows 计划任务，交易日 15:10 跑一次。

## 命令行

不想开界面的时候：

```bash
python -m shortline.cli status              # 环境自检
python -m shortline.cli scan                # 扫一次
python -m shortline.cli scan --at 10:15     # 指定时点（回放测试）
python -m shortline.cli scan --json         # 给脚本用
python -m shortline.cli scan --codes        # 只输出 6 位代码，贴进同花顺自选股
python -m shortline.cli scan --codes --sealed-only   # 只要已封板的
python -m shortline.cli scan --mode banlu   # 半路板模式（20cm 触及 5% + 高开>2% + 首板，次日收盘卖）
python -m shortline.cli sell                # 今天要卖的票
```

`--codes` 输出一行一个 6 位代码，可以直接贴进同花顺「自选股 → 导入」。顺序是可打在前、再按量比升序。

**别用问财复现筛选结果。** 问财只有实时量比，没有全天量比，这个组合它算不出来。要名单就用 `--codes` 搬过去，那一步不重算，零误差。怀疑是口径问题时跑：

```bash
python tools/diag_wencai.py
```

它会拿同一份快照按不同口径各算一遍，打三张表：单条件命中数（拿去和问财逐句对）、累积漏斗、两种量比口径下的名单差异。哪条一断崖就是哪条没对上。

`scan` 在发现可打标的时返回退出码 `1`，可以直接接定时任务：

```cron
# 交易日 09:40 / 10:50 / 13:50 各扫一次，有票才推消息
40 9,10,13 * * 1-5  cd /path/to/trading-desk && python -m shortline.cli scan || \
                    curl -X POST "$WEBHOOK" -d "$(python -m shortline.cli scan --json)"
```

想让它主动推消息，在 `config.json` 填 `notify.webhook_url`（飞书 / 钉钉 / 企业微信机器人都行，会自动识别格式）。

## 半路板模式（v1.0.7 新增，2026-10-24 按真源 §6.4 重写）

网页左上角切「半路板模式」，或命令行 `--mode banlu`。与打板模式是**两套独立条件，不得互搬**：

| | 打板模式（默认） | 半路板模式 |
|---|---|---|
| 买点 | 涨停价排队 | 20cm 票涨到触发价（昨收 ×1.05）就买 |
| 过滤 | 首板 · 开盘 1~3% · 价格≥20 · 20cm 优先 | **高开 >2%** · 开盘未越过触发价 · 首板 |
| 出场 | T+1 竞价挂跌停价清光 | **次一交易日收盘卖**（不分封没封住）；跌回触发价→次日清仓 |
| 硬时点 | 09:40 / 10:50 / 13:50 三轮 | **14:30 后停止接新单** |

半路板三条件（缺一不做）：只做 20cm · 开盘涨幅 >2% 且开盘未越过触发价 · 首板；14:30 前。
扫描建议：触发改不了时点，网页开「自动刷新 60 秒」；手动扫 09:45 / 10:30 / 11:00 / 13:30 / 14:00 / 14:25 六轮。
条件在 `config.json` 的 `banlu_filters` 里改。

⚠️ **旧版两个条件已删**：「量比≥1.5」用全天成交量、「情绪热≥50」用当日涨停家数，进场却在盘中 —— 未来函数，去掉后 +1.73% 掉到 +0.25%；「未封板当日收盘卖」违反 T+1。
⚠️ 可执行口径 +1.381%，但**2024 单年贡献过半**，剔除后 +0.587% —— 按 +0.35~0.45% 净预期，攒够 20 笔模拟记录前不上真仓。

## 限界 —— 比结论更重要

这些不是免责套话，是会影响你今天能不能用的实话。

1. **量比口径已降级为「只看不判」。** 回测里的「全天量比」盘中拿不到，本工具用「日内成交量占比曲线」把当前推进率折成全天口径；曲线来自单只股票 5 个交易日的实测，10:00 的真实占比在 23%~37% 之间波动。**2026-10-24 起量比不再作判据**（旧「量比<1 翻正 +2.33%」在新口径未复现），界面上只显示、不否决。

2. **早盘大概率筛不到票。** 实测 09:57 全市场 5,574 只里，按开盘区间 + 价格 + 首板的组合通过 **0 只** —— 早盘量比普遍 1.3~1.6，价格分布也散。这是策略自身的矛盾，不是 bug。真实执行窗口更可能在午盘之后。

3. **打板的成交概率无法建模。** 一字板占涨停池约 10%，那批期望 +1.91%，比能打到的 −0.47% 还好 —— 越好的越买不进，这是逆向选择。新口径的事件表已剔除一字板。软件只能告诉你「符合条件」，不能保证买得到。

4. **回测没有扣成本。** 印花税、佣金、滑点全都没算。短线换手极高，这块会明显吃掉收益。

5. **数据库不含退市股。** 十年回测存在系统性高估，真实期望比数字更差。

6. **样本期只有十年，且中国股市结构一直在变。** 2018 年 +5.29% 到 2026 年 +2.91%，衰减是可见的。

7. **本工具只做筛选和提醒，不代下单。** 打板要在封板瞬间挂单，机器代办不了，也不该代办。

8. **没有任何一条规则被验证过能穿越牛熊。** 上面所有数字都是历史统计，历史不会简单重复。
