# 策略依据

> 🔴 **2026-10-24 作废声明（先读这一段）**
>
> 本文写于 2026-10-21，用的是**旧事件表**，且打板的人群口径是「只算封住的板」——幸存者偏差。
> 2026-10-24 的数据审计查出 4 个口径错（创业板 2020 前漏、北交所按错、ST 未处理、涨停价取整），
> 重建事件表后真实人群是**触板**（封住 + 炸板，炸板率 35.0%），打板期望是 **−0.682%**，不是本文写的 −0.39%，更不是 +4.10%。
>
> 本文的推导过程和方法论仍可读。**数字一律以知识库真源 `短线交易系统.md` v0.3.5 与 `短线回测_11` 为准：**
> 打板只到打平（五项条件叠加 +0.020%，扣费 −0.13%）；半路板可执行版 +1.381%（净 +0.35~0.45%）。
> 本文里「缩量 + 开盘 3~9% = +4.10%/81.9%」与「量比≥1.5 + 情绪热」两组结论**已作废**。

这份文档记录工具里每一条默认参数是怎么来的。数字全部来自本地十年日K回测，脚本在开发过程中逐轮迭代，这里只保留结论和口径。

## 一、数据与方法

| 项目 | 说明 |
|---|---|
| 数据 | 全市场前复权日K，2016-10 至 2026-10，1,034.3 万行 |
| 覆盖 | 5,576 只，2,429 个交易日 |
| 完整样本 | 打板判定 100,200 笔；目标池 3,805 笔 |
| 涨跌幅 | 按代码前缀：688/689/30 → 20%，8/4/92 → 30%，主板 ST → 5%，其余 10% |
| 量比 | 当日成交量 ÷ 前 5 个交易日均量（含昨日） |

### T+1 是硬约束

A 股当天买入当天不能卖。所有回测都遵守：

- **打板** = T 日以涨停价买入 → T+1 卖出
- **接力** = T+1 开盘买入 → T+2 收盘卖出

> 第一轮回测在这里犯过错：用了「T+1 买入、T+1 收盘卖出」，违反 T+1。修正后接力从 +0.049%/46.7% 变成 **−0.198%/44.3%**，有些结论的方向直接反了。凡是口径写错的回测，数字一文不值。

### 幸存者偏差

第二轮的「打板 +1.647% / 胜率 56.6%」是错的 —— 它只取了**收盘涨停**的样本，等于「知道它封住了才买」。补上 35.6% 的炸板样本后，真实期望是 **−0.39%**。

**任何只统计成功样本的打板回测都是废的。**

## 二、三个动作必须分开

很多人把这三个混成一个「打板」，这是亏钱的起点：

| 动作 | 什么时候买 | 买的是什么 | 回测期望 |
|---|---|---|---|
| **打板** | 涨停价排队，等成交 | 封板的瞬间 | −0.39%（加权）/ 胜率 56.6% |
| **半路** | 涨 7~9% 时买，赌它封 | 封板**之前** | **−0.198% / 44.3%** |
| **接力** | 次日开盘买 | 别人的第二天 | **−0.198% / 44.3%** |

「早上选股、预测它会不会涨停、买进去等次日溢价」—— 这是**半路**，不是打板。它的期望是负的，而且**越像要涨停越亏**：

| 盘中涨幅 | T+1 开盘卖 |
|---|---|
| 涨到 3~5% | −0.069% |
| 涨到 6~8% | −1.069% |
| 涨到 ≥9% | −2.069% |

追高 1% 吃掉 1%，线性关系，没有例外。

## 三、打板的钱全在隔夜跳空里

| 结果 | 占比 | 收益 |
|---|---:|---:|
| 封住 | 64.4% | +2.26% |
| 炸板 | 35.6% | **−5.18%** |
| **加权** | 100% | **−0.39%** |

十年里有九年是亏的。炸板一次要 2.3 次封住才能补回来，而这个比例撑不住。

打板 +1.65% 与接力 −0.20% 差 1.85 个百分点，**全部来自一个隔夜跳空**，不是手法。

## 四、量比是唯一完全单调的变量

把封板样本按量比分档，没有任何一档例外：

| 量比 | 炸板率 | 期望 |
|---|---:|---:|
| <0.5 | 0.4% | **+5.63%** |
| 0.5~0.7 | 1.4% | +4.79% |
| 0.7~0.9 | 6.4% | +3.57% |
| 0.9~1.2 | 16.0% | +2.22% |
| 1.2~2 | 32.9% | +0.05% |
| **≥2** | **42.7%** | **−1.23%** |

这是整份研究里唯一一个干净到没有例外的关系。它也是工具里唯一一个「硬条件」。

换个说法：**缩量涨停是没人抢的涨停，放量涨停是大家都在抢的涨停**。你要的是前者 —— 但前者也最难买到（见第七节）。

## 五、唯一正期望的组合

「缩量 + 开盘涨 3~9%」叠加后：

| 指标 | 数值 |
|---|---|
| 样本 | 4,019 笔 |
| T+1 开盘卖 | **+4.103%** |
| 胜率 | **81.9%** |
| 中位 | +4.071% |
| 分年 | **10 年 10 正** |

分年看衰减明显：

| | 2018 | … | 2026 |
|---|---:|---|---:|
| 收益 | +5.294% | ↓ | +2.912% |
| 胜率 | 93.7% | ↓ | 74.2% |

优势在收窄，但方向没变。这个衰减本身是重要信息 —— 不要按十年前的收益率做仓位规划。

再叠两道筛（收盘价不高于当日均价 1% + 最低点距涨停 <4%）只剩 715 笔，约**三天一只**，收益 +5.025% / 胜率 86.2% / 中位 +5.371%。样本少，只当参考。

## 六、卖出只有一个动作

| 时点 | 收益 |
|---|---:|
| 次日跳空（开盘 vs 前收） | **+2.146%** |
| 次日日内（收盘 vs 开盘） | **−0.283%**（胜率 43.7%） |

钱全在开盘那一刻，之后是净流出。

**结论：T+1 早上 9:25 集合竞价，挂跌停价，一次清光。**

挂跌停价是为了保证成交，不是为了低价卖 —— 集合竞价按最大成交量原则撮合，你报的价只决定「能不能成交」，成交价仍是对手方的最优价。

「次日一字涨停就继续持」只多赚 0.34 个百分点，不值得为它破坏纪律。

---

## 七、买不进是常态

| 项目 | 数值 |
|---|---|
| 一字板占比 | 10.8% |
| 一字板那批的期望 | **+1.91%** |
| 能打到的期望 | **−0.47%** |
| 每天符合条件的机会 | 68.6 个（含所有板，全口径） |
| 目标池每天 | **2.64 只** |

**越好的越买不进。** 这是逆向选择：封单厚说明没人卖，而没人卖的另一个说法就是买不到。

硬追的期望是 +0.07%，等于白干。

**结论：买不进就空仓，等下一个。** 一天 2.6 个机会，不需要抢。

## 八、连板不值得打

| 昨日连板数 | 炸板时亏损 |
|---|---:|
| 首板 | −5.18% |
| 2 板 | **−9.68%** |
| 3 板 | **−11.04%** |

而封住时，连板只比首板多赚 0.5 个百分点。**风险翻倍，收益不变。**

工具默认 `max_boards: 1`。

## 九、封板早晚的影响

日K 只能用「当日最低价距涨停价」（dist）代理封板早晚：

| dist | 占比 | T+1 开盘卖 | 胜率 |
|---|---:|---:|---:|
| <1%（贴着涨停，最早封） | 0.2% | +4.4~5.8% | 77~87% |
| 2~4% | — | +4.01% | — |
| >9%（盘中砸过深坑） | **59.1%** | +1.83% | 66.7% |

早封 +4.963%，晚封 +2.128%，差 2.8 个百分点 —— 但早封只占 0.7%，因为早封的票开盘涨幅普遍已经 9.5% 以上，被「开盘 3~9%」规则排除了。

**实操含义**：绝大多数涨停票都是盘中反复震荡后才封的，**扫描不能只做一轮**，也不能只盯开盘那十分钟。

## 十、限界

1. **量比口径** —— 回测用全天量比（收盘才知道），盘中用日内占比曲线折算，是近似值。曲线样本只有 1 只票 5 天，10:00 真实占比在 23%~37% 之间波动。
2. **早盘筛不到票** —— 实测 09:57 通过 0 只。这是策略自身矛盾：缩量是事后特征，早盘还没缩。
3. **成交概率无法建模** —— 见第七节。
4. **未扣成本** —— 印花税、佣金、滑点都没算，短线换手极高，这块影响大。
5. **数据库不含退市股** —— 系统性高估，真实期望更差。
6. **T+1 跌停卖不出未剔除** —— 少量样本会拉低实际收益。
7. **未区分 ST / 新股 / 北交所** —— 只做排除，未单独建模。
8. **回测用等权指数代替大盘做环境分档**，与原指数有偏差。

## 附：回测脚本

原始脚本在工作区中，按轮次迭代（`bt_howto*.py`、`bt_when.py` 等）。核心口径：

```sql
-- 封板判定（前复权价必先 round 到分，否则与真实涨停价有分位误差）
close_r >= round(prev_close * (1 + limit) , 2) - 0.001
AND close_r >= round(high, 2) - 0.001

-- 量比
volume / avg(volume) OVER (PARTITION BY code ORDER BY date
                           ROWS BETWEEN 5 PRECEDING AND 1 PRECEDING)

-- T+1 开盘卖
(lead(open, 1) OVER (PARTITION BY code ORDER BY date) / 涨停价 - 1)
```
