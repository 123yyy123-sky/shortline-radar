B线路是什么

路线B 是题材 ETF 波段：不打板，只做「强势突破 + 不爆量」的右侧进场。判定只有一份，在工作区 scan_watchlist.py 里（真源 [[B线路操作手册]] / §3A.1、§3A.3），这个页面只是把结果搬过来，并让你改价。

三个价怎么用

买入价 = 你打算或实际成交的价；止损价 = 进场就写死的线，触及按 v1.24 三步判 （X 成立 → 当场卖；不成立 → 观察 30 分钟）；卖出价 = 离场价，默认取 MA20。

仓位的默认算法：试探仓 750 元 ÷（价×100）取整手，所以价位一改，份数跟着变。

候选不是确认：尾盘 14:45~14:55 复核后才算数，16:00 收盘雷达为确认口径。 AI 筛选不构成买卖建议，不覆盖个人止损纪律。

R3 没有「名单」：池 = 全 ETF 缓存里剔掉宽基 / QDII / 债券与贵金属后的结果，所以只能排除、不能挑。 默认空 = 与回测口径一致；排除后会在报告里标注「已排除 N 只 · 回测未覆盖」。

R3 的六条规则（写死，别临场改）

  1. 池：境内题材 ETF，剔宽基、剔 QDII、剔债券与贵金属/商品。
  2. 节奏：每 10 个交易日调仓一次，收盘定名单。
  3. 排序：按过去 60 个交易日涨幅从高到低。
  4. 买谁：先剔收盘在 MA20 下方的，再取涨幅前 2 名（可顺延）。
  5. 空仓开关：沪深300 收盘低于 MA20 → 全部卖出，6,000 元放 1 天期逆回购。
  6. 成交：次日开盘执行，100 份整数手，两只各 3,000 元。

建议买入价、止损价是怎么来的

建议买入价 = 基准日收盘价，只作参考 —— R3 是次日开盘成交，实际按开盘价重算。 挂单上限 = 建议买入价 ×1.02，高开超过它就放弃这只、钱留现金（这条是参考线，不在回测口径里）。

止损价默认 = 该只的 MA20：买入要求站上 MA20，那就守住这条线，收盘跌破 → 次日开盘卖掉这一只， 钱回现金等下次调仓。只卖这一只、不加仓、不摊平、不改轮动节奏。

⚠️ 回测口径里 R3 本身没有个股止损（真源 §三之二 风险第③条：满仓 2 只无止损，21% 回撤是真实成本）。 这里的止损价是叠加的风控线、未回测；不想要就把 config.json 的 r3.stop_mode 改成 none（atr / pct 是另外两种口径）。

止损口径四选一（config.json → r3.stop_mode）

ma20 收盘破 MA20（默认）｜atr 成本 − 1×ATR20｜ pct 成本 ×0.95｜none 不设，只按回测口径走。

推送只在你真要做动作时发（调仓日有买卖、或持仓破止损），同一动作当天只推一次。 回测年化 12.25% / 回撤 21.3% 是 2016-2026 的账，幸存者偏差最重，2025 贡献了 45% 利润。不构成投资建议。

这个工具在干什么

从全市场里筛出「首板 + 开盘涨 1~3% + 价格≥20 元」的票，等你挂涨停价排队。

⚠️ 先说结论：打板在日线上只到打平。全部触板（封住 + 炸板）期望 −0.682%， 炸板率 35.0%。上面这组条件只把炸板率压到 30.6%，四项叠加 +0.020%（扣费 −0.13%）。 这组条件是压炸板率的，不是赚钱门槛，不构成开仓理由。

要翻正，炸板率得 ≤26.05%（现在差 4.4 个点）。日线变量碰不到， 只能等盘中封单数据（2026-10-26 起记录）。真源 [[短线交易系统]] §6.5。

三条最容易做错的地方

  1. 不要提前买。打板必须等它真的封在涨停价，没封就买是另一套玩法（见下面的半路板）。
  2. 不要打连板。首板炸了亏 5%，连板炸了亏 10%~11%，而封住只多赚 0.5 个百分点（连板口径 −1.854%）。
  3. 不要拿旧数字下单。「缩量 + 开盘 3~9% = +4.10% / 81.9%」是只算封住样本的幸存者偏差，已作废。

半路板模式是什么（2026-10-24 重写）

不排队封板，20cm 票盘中涨到触发价（昨收 ×1.05）就买，买的是日内动量延续。 三个条件缺一不做：只做 20cm · 开盘涨幅 >2% 且开盘没越过触发价 · 首板；14:30 后不接新单。

可执行口径 +1.381% / 胜率 50.1%（n=42,257，2020–2026 7/7 年正）。 但 2024 单年 +4.172%（贡献过半），剔除后只剩 +0.587% —— 按 +0.35~0.45% 净预期，不要按 1.38%。

卖出只有一个动作：次一交易日收盘卖，不分封没封住（T+1 合规）。 跌回触发价下面 → 次日开盘清仓。

旧版的「量比≥1.5」「情绪热≥50」是未来函数（用收盘才知道的数）， 「未封板当天收盘卖」违反 T+1，都已删除。去掉后 +1.73% 掉到 +0.25%。

扫描建议：触发改不了时点，开「自动刷新 60 秒」最省事；手动就扫 09:45 / 10:30 / 11:00 / 13:30 / 14:00 / 14:25 这六轮，14:30 硬停。

卖出只有一个动作

T+1 早上 9:25 集合竞价，挂跌停价，一次清光。 次日跳空 +2.15%，次日日内 −0.28% —— 钱全在开盘那一刻，之后净流出。

买不进怎么办

空仓，等下一个。一字板本来就买不到，新口径的事件表已经把它们剔掉了，别拿它当参照。 平均每天只有 2~3 个符合条件的标的，不需要抢。
